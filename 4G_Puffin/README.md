# Puffin 4G LTE

Documentation and software for the standard Puffin 4G LTE board are organized by use case:

- [RC_cars/](../RC_cars/) — RC car hardware setup, control guidance, and control software files.
- [quad_drones/](../quad_drones/) — flight-controller connection and setup guidance, web-based drone control packages, and joystick information.
- [manual/](../manual/) — the Puffin board user manual for Kickstarter backers.

## Professional UAV Users
