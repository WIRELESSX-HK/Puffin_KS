**UAV Pro Puffin** is a project derived from the Puffin platform, specifically designed for professional UAV remote connectivity.

It enables reliable long-range communication between drones and ground control stations over 4G/5G networks. This version is intended for users who are already familiar with **ArduPilot, PX4, MAVLink, Mission Planner, and QGroundControl**.

---

## Hardware

UAV Pro uses **exactly the same hardware** as the KS version of Puffin.

There is no difference at the hardware level — UAV Pro is a **software and system-level extension** built on top of the standard Puffin board, optimized for professional UAV use cases.

## Key Features (Latest Version)

The latest UAV Pro firmware includes the following key capabilities:

- **MIPI camera support**
- Ability to configure Puffin via **Ethernet connection**, including:
  - Signaling server address
  - RTSP camera address
- Real-time **signal quality monitoring** in the UI
- Direct control of **4 PWM outputs**
- Full integration with **MAVLink protocol**

---

## MAVLink Integration

UAV Pro communicates with **Mission Planner** and **QGroundControl** through the MAVLink protocol.

This makes it compatible not only with UAVs (multirotor, fixed-wing), but also with other MAVLink-based platforms such as:

- **Rover (UGV)**
- Custom robotic systems using ArduPilot or PX4

## Notes

UAV Pro Puffin is designed for **professional users**, not as a plug-and-play consumer product.

Before using, you should understand:

- Flight controller integration
- MAVLink configuration and workflows
- Ground control software usage
- RTSP / MIPI camera setup
- Signaling server and network configuration
- Safety considerations for remote operation
